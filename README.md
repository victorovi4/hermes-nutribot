# Нутрибот — дневник питания для Hermes

Бот считает калории и БЖУ из обычных сообщений («записал 2 зефира по 30 ккал», фото этикетки, «кашу как обычно»)
и ведёт дневник. По желанию — приложение прямо в Telegram: экран дня, добавление в два касания, статистика за неделю и месяц.

Работает поверх [Hermes Agent](https://hermes-agent.nousresearch.com). Дневник хранится **у вас**: в своей базе рядом с Hermes
или в вашей Google-таблице. Мы ваших данных не видим.

## Установка

```bash
hermes --profile <ваш-профиль> plugins install victorovi4/hermes-nutribot
hermes --profile <ваш-профиль> nutribot setup
```

Мастер спросит две вещи — где хранить дневник и нужно ли приложение — и сделает остальное сам: создаст хранилище,
запишет цели, добавит правила работы в `SOUL.md` профиля. Потом перезапустите бота (`hermes --profile <профиль> gateway restart`)
и напишите ему: «записал 2 зефира по 30 ккал».

Проверить, всё ли на месте: `hermes --profile <профиль> nutribot doctor`.

## Что умеет бот

- **Продукты с мерками.** «Один зефир» — это штука, «банка Балтики» — 450 мл, «25 г чеддера» — граммы. КБЖУ считает код, не модель.
- **Наборы («стандарты»).** «Кашу стандарт плюс манго» — набор раскрывается на продукты, добавка идёт отдельной позицией.
- **Каталог растёт сам.** Прислали фото этикетки — бот заведёт карточку и в следующий раз найдёт её по названию.
- **Свободные записи.** Ресторан или «половина общей порции» пишутся как есть и правятся числами.
- **ВкусВилл.** Поиск по каталогу магазина с КБЖУ (работает в приложении; сторонний сервис, может быть недоступен).

## Где хранится дневник

| Вариант | Что нужно | Особенности |
|---|---|---|
| Своя база (по умолчанию) | ничего | файл `nutribot.db` в папке профиля Hermes, ответы за миллисекунды |
| Google-таблица | Google, подключённый к Hermes | дневник видно таблицей и можно править руками, ответ ~1 с |

Посмотреть дневник без Google: `hermes --profile <профиль> nutribot export` — файл `.xlsx`, открывается в Яндекс Документах,
Excel и LibreOffice. Яндекс Таблицы рабочим хранилищем быть не могут: у них нет программного доступа к ячейкам.

## Приложение в Telegram (по желанию)

| Куда ставить | Кому подходит | Инструкция |
|---|---|---|
| Свой сервер | у кого Hermes на сервере или есть любой VPS | [docs/app-docker.md](docs/app-docker.md) |
| Яндекс Облако | кто не хочет свой сервер; дневник — только Google-таблица | [docs/app-yandex-cloud.md](docs/app-yandex-cloud.md) |

Приложение открывается кнопкой в чате бота. Вход — по подписи Telegram: чужой человек данных не получит.

## Если что-то не работает

1. `hermes --profile <профиль> nutribot doctor` — покажет, чего не хватает.
2. Бот не видит инструмент `nutrition_log` — проверьте, что плагин включён: `hermes --profile <профиль> plugins list`.
3. Бот игнорирует правила — проверьте, что блок `nutribot` есть в `SOUL.md` профиля, и перезапустите гейтвей.
4. Приложение не открывается из-за рубежа — адреса Яндекс Облака отвечают только российским сетям; на своём сервере такого ограничения нет.

## Для разработчиков

```bash
uvx --quiet pytest -q                # все проверки
deploy/install_plugin.sh             # поставить этот checkout в профиль Hermes
HERMES_HOME=<профиль> python deploy/dev_server.py    # приложение локально
```

Хранилище спрятано за одним интерфейсом (`nutricore/store.py`); обе реализации проходят один и тот же набор тестов
(`tests/test_store_contract.py`). Добавить третье хранилище — значит реализовать этот интерфейс и пройти те же тесты.
