# Приложение в Яндекс Облаке

Подходит, если нет своего сервера. Дневник при этом должен лежать в Google-таблице: функция в облаке не достанет
до базы на вашей машине. Расходы при одном пользователе обычно укладываются в бесплатные лимиты, но тарифы проверьте сами.

## Что понадобится

- аккаунт Яндекс Облака и установленный `yc` (`yc init`);
- сервисный аккаунт с правами на функции, шлюз и хранилище;
- служебный Google-аккаунт, которому открыта только ваша таблица дневника (см. ниже);
- токен бота и ваш Telegram-id.

## Служебный Google-аккаунт

1. В Google Cloud Console создайте служебный аккаунт и ключ к нему (JSON).
2. Откройте вашу таблицу дневника и дайте этому аккаунту (его адрес вида `...@....iam.gserviceaccount.com`) право редактора.
3. Проверьте, что ключ не даёт доступа ни к чему другому: у служебного аккаунта не должно быть ролей в проекте.

## Выкладка

```bash
cp deploy/cloud.env.example deploy/cloud.env && nano deploy/cloud.env   # имена ресурсов, id таблицы, ваш Telegram-id
deploy/deploy_cloud.sh                                                  # напечатает адрес приложения
python3 deploy/set_menu_button.py                                       # кнопка в меню бота
```

Проверка: `python3 deploy/check_cloud.py` — пройдёт по всем маршрутам, включая запись и удаление тестовой записи.

## Ограничения

- Адреса `*.apigw.yandexcloud.net` отвечают только российским сетям: из-за рубежа или под VPN приложение не откроется.
- Секреты по умолчанию хранятся в переменных версии функции. Если сервисному аккаунту выдать роль `lockbox.payloadViewer`,
  запустите `USE_LOCKBOX=1 deploy/deploy_cloud.sh` — тогда они переедут в Lockbox.
